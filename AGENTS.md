# Lightform agent instructions

Read PROJECT_PLAN.md and CONTRIBUTING.md before changing the app. Use feature branches and Conventional Commits. Keep existing work intact. Commit only files in scope and never publish or deploy without authorization.

Keep geometry calculations UI-independent and use millimetres throughout. Generate lamp previews procedurally from measured primitives. Add useful silhouette, aperture and seam detail without copying product meshes, markings, or textures. Lamp previews must be excluded from STL exports.

Run the applicable checks and report verification gaps. Treat physical retention, heat, and optical behavior as unverified until tested on hardware. Keep documentation and code comments in English. Preserve MIT for source and CC0 notices for original generator output.
