# Editor design

Kind: software workspace, for photographers designing printable light accessories.
Palette: Lemon Granite Morning. Lemon (#F3E308) marks primary actions and the
BeamKit mark. Deep blue (#2C4C5C) anchors the header and light-mode text.
Granite (#B8BFC1) and slate (#6C8494) inform the workspace, controls, and
viewport. Light and dark modes use related tints and shades. The multicolor
preview and 3MF use lemon for the outer shell and clips, granite for the inner
shell, and near black (#202124) for the grid.
Voice: technical, direct, dimensional; no invented performance or fit claims.
Primary action: Export 3MF. Portable backup: Save JSON.

The real product UI is the page. A marketing hero, full-screen promotional sections,
stock photography, animated marketing moments and a sales footer would obstruct the
working CAD editor, so those taste-plugin recipes are not applied.
Use its discipline for typography, equal panel padding, one accent, visible hover
and focus, readable contrast, and responsive inspection of the actual product.

The desktop preview sits beside the parameters panel. The parameter tabs stay
visible while controls scroll. The header holds the project tools and export
action. The toggle above the preview switches between the lit assembly and the
accessory on the print bed. On phones the editor fits within the viewport and
only the parameter fields scroll. The panels stack in portrait and sit side by
side in short landscape windows.

No external fonts, photographs, source product images, meshes, third-party logos,
or textures are needed. All runtime assets remain available offline.
