# Editor design

Kind: software workspace, for photographers designing printable light accessories.
Palette: the project's Opaline canvas (#F4F4F6), secondary surface (#E7E7E7),
borders (#D2D2D4), coral action (#FF634A), dark ink. Preserve the established palette.
Voice: technical, direct, dimensional; no invented performance or fit claims.
Primary action: Export STL. Portable backup: Save JSON.

The real product UI is the page. A marketing hero, full-screen promotional sections,
stock photography, animated marketing moments and a sales footer would obstruct the
specified three-column CAD workspace, so those taste-plugin recipes are not applied.
Use its discipline for typography, equal panel padding, one accent, visible hover
and focus, readable contrast, and responsive inspection of the actual product.

Desktop keeps catalogue and projects on the left, an original live procedural
preview in the center, and parameters on the right. Sidebars scroll independently;
the viewport, dimension strip and generation state remain visible. On phones the
setup and settings panels collapse, and the preview retains touch orbit controls.

No external fonts, photographs, source product images, meshes, third-party logos,
or textures are needed. All runtime assets remain available offline.
