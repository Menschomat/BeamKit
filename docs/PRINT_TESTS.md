# P96L collar fit-test record

Status: not printed. Printer family: Bambu Lab. Nozzle: 0.4 mm.
Material and layer height: choose and record in the slicer. No material is
currently qualified for heat exposure on this lamp.

Select **Advanced test tools → Fit coupon only** and export STL before printing a full accessory. This produces only the
original collar, front support and four prototype corner hooks, without the honeycomb,
diffusion material, procedural lamp preview, or access-volume overlays.

## Slicer checks, left to the user

- Import in millimetres and compare bounding dimensions with the app.
- Confirm one connected part, open apertures and all intended thin walls.
- Inspect the spring hooks, ramps, first-layer contact and support requirements.
- Use the STL’s front-down placement. Start at 0.20 mm layers, four walls and
  0–10% infill, then inspect the sliced paths. Use the material profile’s speed
  settings and reduce outer wall speed if the ramps need it.
- Choose orientation, wall paths, layer height and material deliberately.
- 0.8 mm honeycomb walls target two nominal 0.4 mm nozzle paths. Actual extrusion
  widths and wall generators vary: this is not a slicing guarantee.

## Hardware checks

Record lamp revision, material, nozzle, layer height, clearances and observations.
Start with 0.3 mm fit clearance **per side**, 1.6 mm support thickness, 14.5 mm
corner clip depth and 2.1 mm hook reach. These are experimental defaults.
Do not force a tight part onto the lamp. Change clearance and print another fit
test if necessary. Access cuts cannot remove less than the mandatory keepouts.

Confirm attachment and removal, unplugging/plugging USB with the intended cable,
full switch/button travel, both dial movements with fingers, mounting-screw
access and cooling access. Test retention under expected handling separately;
no drop resistance or secure overhead retention is claimed. Check for deformation
at operating temperature using the actual lamp, brightness and material.

Only then evaluate a modular connection: interface dimensions, tolerance settings,
engagement direction, retention features and separate mount/attachment exports.
No modular file is currently offered as a tested mechanical connection.

Optical comparisons need controlled photos or lux measurements at a recorded
distance. A honeycomb restricts spill; a holder retains commercial diffusion
material. Neither geometry alone yields a calibrated beam angle or transmission.


For a pattern comparison, use the same lamp brightness, distance, camera
position, and manual exposure on a blank wall. Start with 12 mm depth and
0.8 mm walls for honeycomb, rectangular eggcrate, and louvers. Photograph
both orientations of the directional patterns. Check spill and brightness
along both axes before choosing a preset for a shoot.
